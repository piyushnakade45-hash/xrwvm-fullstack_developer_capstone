# Cars Dealership Full-Stack Capstone

**Repository name:** xrwvm-fullstack_developer_capstone

**Project name:** Cars Dealership Full-Stack Capstone

A full-stack web application for a national car retailer. Users can browse dealerships, filter them by state, and read and post reviews.

Built with React, Django, Node.js, Express, MongoDB, SQLite and Docker, and deployed on IBM Cloud Code Engine.
